Entry for the make.fun competition `news-image-20261126`: sum up the world's
news of Thursday 26 November 2026 in one image.

See the competition at https://make.fun/bounty/news-image-20261126

## The image

A front-page-style collage, 1024x1024, with the banner
"THE WORLD IN ONE DAY — Thursday 26 November 2026" and six panels covering
the day's most consequential stories across regions and fields:

1. **Ras Tanura refinery hit** — Houthi forces attacked Saudi Arabia's
   Ras Tanura oil refinery, causing fires.
2. **Mines in the Hormuz Strait** — two oil tankers hit naval mines in the
   Strait of Hormuz.
3. **Ukraine strikes Russian refineries** — Ukrainian forces struck two
   Russian oil refineries overnight; Putin vowed retaliation.
4. **COP31 ends with no deal** — the climate summit failed to produce an
   agreement.
5. **Pakistan's first astronaut flies** — Pakistan's first astronaut joined
   China's Shenzhou-24 mission to the Tiangong space station.
6. **Mumbai remembers 26/11** — India marked the 18th anniversary of the
   26/11 Mumbai terror attacks.

The image was generated for this entry (editorial illustration style) and is
stored in this repository as a JPEG. `main.py` copies it byte for byte to
`$MAKEFUN_OUTPUT_DIR/entry.png`, so every run writes identical output.
The file is 286,634 bytes, under the 1 MiB cap.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
